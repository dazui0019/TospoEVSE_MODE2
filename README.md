## News / Change History

### 2024/10/24

- 添加`FaultHandler`，修改`HardFault_Handler(void)`函数，方便后续调试。

### 2024/10/23

- 添加LCD驱动。
- basic os不支持硬件浮点, 如果出现`HardFault`可以检查一下有没有关闭硬件浮点。
- 将`MODE3`的充电状态机同步过来。
- 完善电压、电流采样算法。
- 完成过(欠)压和过流的检测以及处理。

### 2024/10/10

- 添加RCD检测功能。

### 2024/10/09

- 在同时开启`AC采样任务`、`温度检测任务`和`充电主任务`的状态下(开启所有必要的ADC采样), 完成运行测试。
- 完成初步的故障处理流程。
- 完成过压和欠压的故障处理测试。
- 完成车端二极管S1的检测函数, 已加入到充电流程中。
- 完成PE断线检测。

### 2024/10/06

- 交流部分的采集, 为了适应不同的电流频率, 采用`FREQ_IN`触发。
  - 但是`FREQ_IN`这部分电路有点问题, 需要再确认一下。

### 2024/10/05

- 新版原理图删除了粘连部分的`ADC`检测, 所以新的ADC分组如下:
  - ADC0_R: 交流部分的采样(电压、电流、接地检测)。
  - ADC1_I: 温度检测
  - ADC2: CP检测
- 在开发板上完成新版ADC方案的CP采集和温度采集测试。

### 2024/09/29

- `CP`检测修改到ADC2, 在`TIMER2`中断中由软件触发, 同样开启ADC2的DMA模式。
- 完善`CP`占空比设置函数, 增加对PWM模式的判断。

### 2024/09/27

- 修改充电状态机。
- `CP`不单独使用一个任务, `CP`电平的判断在充电主任务中完成。

### 2024/09/26

- 修改断地检测阈值。
- 完成温度采集测试。

### 2024/09/25

- 完成基本的CP交互测试。
- 简化CP检测任务，取消状态机，只做CP电平的检测不做CP断线检测，错误只保留了电平错误(除了12V、9V、6V以外的电平会报错)。
- 完成对CP断地(枪头断地)和电源断地的简单处理。

### 2024/09/24

- 在ADC0上完成基本的继电器粘连测试。

### 2024/09/23

- 在充电桩板上，完成CP输出以及CP电压采样测试。
- 完成电压、电流采集测试。
- GD32F303Cx系列无TIMER7，所以ADC2的采样触发信号改为TIMER1_CH2的比较事件，`ADC2_EXTTRIG_REGULAR_T1_CH2`。
- 当CP输出的定时器为PWM0模式时，触发的ADC采样会采到CP_PWM的低电平上，所以TIMER2的PWM输出模式改为PWM1(相当于反相)。
- 完成接地检测测试。
- 完成继电器控制测试。

### 2024/09/22

- 完成单个通道的交流电压平均值采集测试。
- 修改CP电压滤波函数。

### 2024/09/21

- 完成ADC内部参考电压的采集。
- 编写温度采集的初步方案(软件触发)。

### 2024/09/18

- 初步完成主板部分的串口通信开发.

### 2024/09/13

- 完成CP输出以及CP电压检测电路的逻辑测试(验证原理图)。
