## News / Change History

### 2024/11/3

- 当CP电平切换回9V时也能清除S1二极管丢失错误。

### 2024/11/2

- 删除独立的`CP_LOST`和`CP_ERROR`状态, 统一放到`EVSE_FAULT`状态中处理, 修复充电中发生`PE_LOST`错误时会触发`FaultHandler`的问题。
- 添加一个宏(`CUR_ERR_CAN_BE_CLEAR`), 用于控制过流错误能否被清除。
- `S1`二极管丢失错误也会进入`EVSE_FAULT`状态。
- 优化`S1`二极管丢失错误的UI显示位置。

### 2024/11/1

- 添加最大充电电流切换函数。
- 修改`CP`模块中的电流设置函数。
- 可以用按键控制电流大小。
- 可以通过按键设置延时时间。
- 将UI数据结构体定义为数据类型。
- 同步RGB状态。
- 完成基本的交互测试。
- 完成基本的故障显示。

### 2024/10/31

- 添加蜂鸣器驱动。
- 修改`CP`相关外设。
- 修改`S2`二极管检测引脚。
- CP状态检测函数(`cp_state_t get_cp_state(float vol)`), 转换为电压后再进行比较(原来是ADC原始值)。
- 修改继电器控制逻辑，先`12V`吸合继电器, `1s`后切换至`7V`降低线圈功耗。

### 2024/10/28

- 完成初步的故障处理流程。
- 完成过压和欠压的故障处理测试。

### 2024/10/05

- 新版原理图删除了粘连部分的`ADC`检测, 所以新的ADC分组如下:

  - ADC1_I: 温度检测
  - ADC2: CP检测
- 在开发板上完成新版ADC方案的CP采集和温度采集测试。

### 2024/09/27
